# V23.1 依 Google 專案資料夾追蹤進度

對應現行 Web App（程式3／V22 流程）的標準 8 個子資料夾，在統整版內做成「證據 → 階段 → 下一步追蹤」。

## 怎麼對

| 資料夾 | 階段 | 有檔或有完成工作／回報 | 建議追蹤 |
|--------|------|------------------------|----------|
| 01_合約訂單銷貨驗收文件 | 合約／下單 | 已簽約證據 | 補合約／訂單 |
| 02_圖面資料 | 圖面送審 | 已送審／竣工圖 | 補圖、送審 |
| 03_專案追蹤記錄 | 追蹤紀錄 | 會議／協調紀錄 | 更新追蹤 |
| 04_施工照片 | 現場施作 | 到場照片 | 施工／除錯 |
| 05_驗收文件 | 驗收 | 驗收單 | 辦理驗收 |
| 06_教育訓練 | 教育訓練 | 教材／簽名 | 安排訓練 |
| 07_請款文件 | 請款 | 請款包 | 準備請款 |
| 08_其他文件 | （不計進度） | 雜檔 | — |

工作標題含「圖面、施工、驗收…」會自動歸到對應階段。  
**不會自動改「專案狀態」**，只建議下一步。

## 每天怎麼用

1. **我的收件匣**：自己的逾期／到期工作。
2. **進度追蹤**：哪個專案卡在哪一段；按「建立下一步追蹤」產生正式工作。
3. 點進專案：掃描該案 Drive，看各夾檔數與最新檔。
4. 做完一段就**回報同一工作**，檔案上傳到對應子資料夾。
