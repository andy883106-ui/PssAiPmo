# PSS AI-PMO V23.2.0 安裝與測試

這是**一支** Web App。請開**新的** Apps Script 專案（或獨立副本）測試，不要直接覆蓋目前正式 `/exec`，驗收通過再改正式部署。

## 1. 建立專案

1. https://script.google.com → 新增專案，名稱例如 `PSS AI-PMO V23 統整測試`。
2. 刪除預設 `Code.gs`。
3. 把 `gas/unified/` 內**所有** `.gs`、`.html`、`appsscript.json` 依**相同檔名**貼上。
   - 必須有：`Index.html`、`App.html`、`Styles.html`、`HubEditor.html`、`TenantEditor.html`
   - V23 新檔：`23_InboxWorkflowService.gs`～`28_WorkTemplateService.gs`（含資料夾進度與標準工作樣板）

檔名不可改（Apps Script 用檔名 include）。也可解壓 `gas/PSS_AI_PMO_V23.2.0_unified.zip`。

## 2. 授權與安裝

在編輯器執行（需能開營運試算表與 Drive 根目錄的 Google 帳號）：

```javascript
installPssAiPmoV23()
```

再執行：

```javascript
runV21SelfTests()
validatePssAiPmoV23()
```

若 `V21_專案主檔` 仍是空的，再執行（只**新增** `V21_` 分頁，不改舊表）：

```javascript
runConfirmedMigrationV21()
```

## 3. 部署測試 Web App

1. 部署 → 新增部署作業 → 網頁應用程式。
2. 執行身分：你的帳號（測試階段）。
3. 對象：網域內／測試人員。
4. 部署後開 **/exec**（不要用 /dev 當正式測試）。
5. 若空白頁，改開 `你的網址?diagnostic=1`。

若已部署過，請「管理部署作業 → 編輯 → 新版本」再更新。

## 4. 建議驗收

- [ ] 我的收件匣：頂部摘要、今日待回報分組（若常為空，核對「人員資料」Email）。
- [ ] 新增工作：選停車場／門禁專案後可選標準樣板。
- [ ] 專案詳情 → 套用缺件樣板；進度追蹤 → 建立下一步追蹤。
- [ ] 回報此工作（不完成）後，該工作離開「今日待回報」；「回報並完成」才完成。
- [ ] 專案搜尋 1 字篩選；工作日曆、週四會議、教育訓練、報價可開。
- [ ] `?tool=hub`、`?tool=tenant`；工具頁 NAS 匯出與系統檢查。
- [ ] 「進度追蹤」可依缺合約／圖面／施工／驗收／請款分組。

細節：`docs/V23.1_資料夾進度追蹤.md`、`docs/V23.2_標準工作樣板.md`。

## 5. NAS 手動同步

1. 在系統按「立即匯出」。
2. 下載該 Drive 資料夾。
3. 公司網路用 rclone 或 FreeFileSync **單向**複製到例如 `\\NAS\部門\PSS_AI_PMO\日期\`。
4. 不要在 NAS 改完再傳回 Google（避免雙寫）。
