# PSS AI-PMO V23.1.0 安裝與測試

這是**一支** Web App。請開**新的** Apps Script 專案（或獨立副本）測試，不要直接覆蓋目前正式 `/exec`，驗收通過再改正式部署。

## 1. 建立專案

1. https://script.google.com → 新增專案，名稱例如 `PSS AI-PMO V23 統整測試`。
2. 刪除預設 `Code.gs`。
3. 把 `gas/unified/` 內**所有** `.gs`、`.html`、`appsscript.json` 依**相同檔名**貼上。
   - 必須有：`Index.html`、`App.html`、`Styles.html`、`HubEditor.html`、`TenantEditor.html`
   - 新檔：`23_InboxWorkflowService.gs`、`24_NasExportService.gs`、`25_FeatureGuideService.gs`、`26_Installer.gs`、`27_FolderProgressService.gs`

檔名不可改（Apps Script 用檔名 include）。

## 2. 授權與安裝

在編輯器執行（需能開營運試算表與 Drive 根目錄的 Google 帳號）：

```javascript
installPssAiPmoV23()
```

再執行：

```javascript
runV21SelfTests()
validatePssAiPmoV23()
```

若 `V21_專案主檔` 仍是空的，再執行（只**新增** `V21_` 分頁，不改舊表）：

```javascript
runConfirmedMigrationV21()
```

## 3. 部署測試 Web App

1. 部署 → 新增部署作業 → 網頁應用程式。
2. 執行身分：你的帳號（測試階段）。
3. 對象：網域內／測試人員。
4. 部署後開 `/exec`（不要用 `/dev` 當正式測試）。
5. 若空白頁，改開 `你的網址?diagnostic=1`。

## 4. 驗收清單

- [ ] 首頁「我的收件匣」有分組（若帳號對不到人員姓名，先核對「人員資料」Email）。
- [ ] 專案搜尋輸入 1 個字即篩選；空白連點兩下出現清單。
- [ ] 工作：回報此工作 **不會** 把任務標完成。
- [ ] 「回報並完成」才完成。
- [ ] 同一工作連續兩天回報，回報紀錄有兩筆、工作仍是同一 ID。
- [ ] 新增關聯派工會出現在對方收件匣（主管）或自己收件匣。
- [ ] 刪除工作後目前工作／日曆消失；狀態為已刪除（軟刪）。
- [ ] 工作日曆、週四會議、教育訓練、報價仍可開。
- [ ] `?tool=hub`、`?tool=tenant` 可開編輯器。
- [ ] 工具與同步 → NAS 匯出，Drive 出現 `04_匯出與同步/NAS_待同步/日期_時間/`。
- [ ] F1 或「？ 說明」打得開。
- [ ] 「進度追蹤」可依缺合約／圖面／施工／驗收／請款分組。
- [ ] 開啟專案可見 01～07 資料夾檔數與「建立追蹤事項」。
- [ ] 「目前工作」依階段分組。

## 5. NAS 手動同步

1. 在系統按「立即匯出」。
2. 下載該 Drive 資料夾。
3. 公司網路用 rclone 或 FreeFileSync **單向**複製到例如 `\\NAS\部門\PSS_AI_PMO\日期\`。
4. 不要在 NAS 改完再傳回 Google（避免雙寫）。
