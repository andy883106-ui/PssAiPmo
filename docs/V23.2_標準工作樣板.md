# V23.2 標準工作樣板與每日摘要

延續 V23.1「資料夾 → 階段 → 下一步」，補上**每天真正好用的建單與回報節奏**。

## 標準工作樣板

依專案「系統類型」提供 01～07 階段標題：

| 系統類型 | 範例標題 |
|----------|----------|
| 停車場系統 | 停車場車道／車位配置圖送審並上傳至 02_ |
| 門禁系統 | 門禁控制器／讀卡機安裝除錯並上傳至 04_ |
| 訪客系統 | 訪客報到流程驗收並上傳至 05_ |
| 電梯梯控系統 | 梯控樓層權限／配線圖送審… |
| 批價機系統 | 批價／繳費流程驗收… |
| 其他／空白 | 回落「通用」樣板（與階段 suggestTitle 對齊） |

### 怎麼用

1. **新增工作** → 先選專案 →「標準工作樣板」下拉選一筆 → 標題／類型／期限自動帶入 → 儲存。
2. **專案詳情 → 雲端資料夾進度 → 套用缺件樣板**  
   只對「尚缺雲端證據」且沒有同階段進行中工作的階段建立事項。

## 我的收件匣（每日更清晰）

頂部摘要：逾期／今日待回報／7 日內到期／我的進行中。

分組順序：

1. 逾期未完成  
2. **今日待回報**（狀態＝目前處理，且今天還沒對該工作寫回報）  
3. 7 日內到期  
4. 今日新派工  
5. 後續任務（含階段追蹤／事項）  
6. 進行中  

並顯示最多 3 筆「目前處理」捷徑。

若收件匣常為空：人員資料表的 Email 需對到目前 Google 登入帳號。
