## 統整版保留的功能

- 專案主檔、雲端 8 子資料夾、關聯專案、封存
- 工作跨日：一筆工作 + 多日回報（`關聯工作ID`）
- **回報此工作（不完成）**／**回報並完成**／完成（不追蹤）
- 我的收件匣：逾期、7 日到期、今日派工、後續任務
- 工作日曆、週四會議、教育訓練、報價設備
- 多附件、關聯搜尋、重複工作檢查
- 軟刪除 + `V23_刪除工作紀錄`（可復原）
- `V23_任務回報歷程`
- 專案報告設定
- NAS 待同步包（CSV + 說明，手動複製到公司 NAS）
- HUB 圖檔編輯器、租戶底圖編輯器
- Lark／部門試算表連結（對照，非即時雙向）

## 建議日常流程

1. 計畫／派工：專案管理 → 新增工作（可從舊專案關聯）。
2. 每天：收件匣 → 點任務 → **回報此工作**（同一 Task 跨多日）。
3. 整項結束：**回報並完成**；不必追蹤則「完成（不追蹤）」。
4. 週三／週四：週四會議刷新、產出紀錄。
5. 有公司網路時：工具與同步 → NAS 匯出 → 複製到 NAS。
