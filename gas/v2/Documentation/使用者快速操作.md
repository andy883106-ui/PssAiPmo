# R5.3 使用者快速操作

## 工作事項
1. 到「工作事項」。
2. 「詳情」看關聯專案、回報、檔案與學習資源。
3. 「回報」直接帶入原任務建立每日回報。
4. 「編輯」會先顯示已有附件，再決定是否追加新檔。
5. 重複工作按上方「檢查重複工作」，保留正確一筆後再刪除多餘項。

## 每週工作／週四會議
1. 每天都可進入，不必等週四。
2. 按「重新檢視」重新計算本週、下週、未完成與人員回報。
3. 在本週／人員／下週清單選「加入會議追蹤」。
4. 開會時在「會議追蹤清單」修改回報與決議。
5. 選擇「完成並回報」或「本週完成＋下週追蹤」。
6. 會後整理完成再按「產出會議紀錄」。

## 教育訓練
1. 先選「系統」。
2. 再選該系統的課程。
3. 課程內依序查看教材、完成確認、測驗、簽名。
4. 主管在課程第一頁可進入「編輯課程／手冊資料」。

## 功能說明
登入後右上方按「？ 功能說明」，或鍵盤按 F1。
