PSS AI-PMO｜功能說明

V20.5 R5.3｜工作回報、週會與教育訓練整合版
工作事項編輯／回報／刪除
週會每日可重新檢視
教育訓練系統 → 課程 → 內容
附件既有先顯示、新檔追加
建議操作流程：專案 → 派工 → 工作回報 → 每週工作監看 → 週四會議 → 完成／下週追蹤 → 會議紀錄

工作事項

每筆工作可直接詳情、回報、編輯、完成或刪除。

  1. 編輯時先顯示已上傳附件。
  2. 新增附件只追加，不覆蓋舊資料。
  3. 「檢查重複工作」會依專案＋內容＋負責人分組。
  4. 刪除前先保留刪除稽核紀錄。

專案／關聯詳情

關聯詳情包含工作、專案、回報、檔案路徑與推薦學習。

  1. 專案報告可設定是否顯示。
  2. 可編輯回報狀況、摘要與下次追蹤日。
  3. 可由專案直接新增工作回報。

每週工作／週四會議

不是單次會議快照；主管每天都可按「重新檢視」。

  1. 本週工作、人員回報、下週安排、未完成監看。
  2. 自行選入真正需要開會的項目。
  3. 會中可儲存回報、完成、或本週完成＋建立下週任務。
  4. 會後整理後再產出正式會議紀錄。

教育訓練中心

先選系統，再顯示課程，點課程才開啟內容。

  1. 教材／附件。
  2. 學員完成確認。
  3. 課程測驗。
  4. 學員簽名。
  5. 主管查詢與課程／手冊設定。
資料規則：不要因為再次編輯就重複上傳同一份檔案。先查看「既有附件」，只有新版或補充資料才新增。
按下方「系統檢查」可確認重要 API 與資料表是否完整。
