## 來源分析

來源檔：`PSS停管業務部PM管理.xlsx`  
來源分頁：`繪圖申請進度表`

- 資料列：240 筆。
- 有「送出圖面日期」：221 筆，日期範圍 2025-01-01～2026-07-02。
- 已送審專案名稱：91 種。
- 有 Google Drive 超連結：141 筆。
- 有送審日期但沒有超連結：80 筆。
- 有送審日期但圖面名稱空白：3 筆；匯入時以「專案名稱＋送審圖面」代替標題。

以 2026-08-14 正式 `V21_專案主檔` 150 個專案唯讀驗證：

- 可安全對應 179 筆來源、52 個專案。
- 兩筆來源同時對應兩個專案，因此預計寫入 181 筆圖面紀錄。
- 181 筆中 114 筆含可點擊連結、67 筆只有圖面名稱。
- 42 筆在目前專案主檔找不到對應，略過；歧義資料 0 筆。
- 若 Apps Script 已切換到另一份 V2.0 精簡資料庫，畫面會以該資料庫重新計算，數量可能不同。

## 寫入規則

1. 只處理有「送出圖面日期」的列。
2. 執行時重新讀取目前目標資料庫的 `V21_專案主檔`，不把專案 ID 寫死在程式內。
3. 來源沒有場地代號，因此以專案名稱、常見別名及字詞正規化比對；必須唯一命中才寫入。
4. 無法比對及同時命中多個專案的列只列入統計，不會寫入。
5. 每筆安全命中的資料寫入 `V21_圖面狀態`：送審狀態＝`完成`、送審日期＝來源日期、圖面標題＝來源圖面名稱、附件連結＝原儲存格超連結。
6. 同步將命中專案的 `圖面送審狀態` 更新為 `完成`；不修改專案進度、專案狀態或工作事項。
7. 圖面 ID 由來源列與專案 ID 組成，可安全重複執行；再次同步會更新同一筆，不會重複新增。

## 操作方式

1. 更新並部署 V21.3.0 後，先執行 `setupPssAiPmoV21()`。
2. 在網頁點「專案管理」→「同步繪圖進度表」。
3. 程式先顯示來源筆數、可唯一配對筆數、缺連結筆數、未配對及歧義筆數。
4. 確認後才正式寫入；未配對與歧義資料自動略過。
5. 同步完成後，點任一專案的「目前專案」可查看全部已送審圖面；有網址者顯示「開啟圖面」。

也可先在 Apps Script 編輯器執行 `previewDrawingProgress20260814V21()`，確認結果後再執行 `runImportDrawingProgress20260814V21()`。

## 安全限制

- 若 `V21_專案主檔` 尚未建立或沒有資料，正式匯入會停止，避免在空白主檔建立不完整專案。
- 原始 Excel 與舊資料分頁不會被修改。
- 正式 Web App 需 Google 帳號授權；外部未登入環境無法讀取私有專案清單，因此最終配對數以程式內的預覽結果為準。
