# V21.6.0 報價設備中心

## 操作流程

1. 從設備卡按「加入報價」。
2. 在已選設備區修改數量或單價，或按「移除」。
3. 按「建立報價單」，使用專案快篩選擇場地。
4. 儲存後同時建立 Google 試算表與 PDF。
5. 後續從「最近報價單」開啟檔案、載入編輯，或另存為其他專案報價。

## 檔案位置

每張報價固定歸檔在：

`專案資料夾／01_合約訂單銷貨驗收文件／報價單`

同一報價每次編輯會升版，V1、V2、V3 各自保存，不覆寫前一版。

## 設備主檔

`V21_報價設備` 保存新設備及舊品項的修改覆寫資料。可維護：

- 大分類、分類、品號、名稱／規格與單位
- 成本、建議報價、供應商與說明
- 圖片連結或上傳圖片
- 排序關鍵字
- 啟用／封存狀態

設備排序以關鍵字優先，接著按分類、名稱與品號排列。系統以相同品號優先判斷疑似重複；無品號時才使用正規化後的名稱與單位。

## 安全原則

設備「刪除」採封存處理。封存設備不再供新報價選擇，但歷史報價明細仍保留原名稱、品號、單價與圖片連結，避免舊報價損壞。
