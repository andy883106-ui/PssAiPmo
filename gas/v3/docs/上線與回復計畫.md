# V21.1 上線與回復計畫

## 為何可避開舊程式問題

V21.1 使用新的 Apps Script 專案、新部署 ID、單一 API 閘道與獨立前端，不載入舊 Web App 的 V17～V20.5 函式、NAS、一般會議或舊快取。資料則沿用已在正式活頁簿運作的 `V21_` 分頁，避免再做一次資料搬移。

## 上線

1. 備份 Apps Script 專案與正式試算表。
2. 建立全新 Apps Script 專案並設定目前正式活頁簿為 V21 目標。
3. 執行自我測試、V21.1 分頁建置與健康檢查。
4. 新舊 Web App 並行 3～5 個工作天，抽查新增專案、工作、回報、教材、會議快照、設備圖片及報價。
5. 確認後停用舊表單與排程觸發器；保留舊程式唯讀，不刪除。

## 回復

若發生阻斷性問題，停用 V21.1 觸發器並把入口切回舊 Web App。V21.1 只新增或更新 `V21_` 分頁，舊分頁沒有被刪除；保留 V21.1 寫入資料供比對，不做破壞性回復。

## 驗收重點

- 工作標題顯示場地名稱，且只出現進行中／待追蹤。
- 新增專案同時產生唯一場地代號與雲端資料夾。
- 狀態建議不會自動覆寫人工狀態。
- 人員與事件標題可從既有資料快篩。
- 專案圖片、CAD、文件清單依時間新到舊。
- 教材可新增、編輯、關聯專案並上傳附件。
- 週四會議重掃後不出現完成或重複事項。
- 設備卡可更換圖片、查看既有設備並加入報價。
