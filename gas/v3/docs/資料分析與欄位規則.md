# 正式資料庫分析與 V21.1 規則

分析日期：2026-08-13（Asia/Taipei）  
來源試算表：`PSS_AI_PMO_專案管理平台`（ID `11ndvBcV0geEF7oJv1kX28BuC4_kAKnl37wUhL-Rx27g`）

## 現況

目前活頁簿已存在並使用 V21 資料：150 個專案、466 件工作、380 筆回報、869 筆統一歷程。V21.1 因此採就地升級 V21 結構，不重複匯入舊資料。

教育訓練資料分散在管理、文章、附件、題庫與完成紀錄；報價品項與設備主檔沒有共同圖片欄；週四會議舊快照可能落後於工作資料。這三個模組改以專案 ID 作共同鍵，但維持各自資料表，避免相互覆寫。

## 核心規則

- 目前工作只包含「進行中／待追蹤」。待安排、待確認、卡關及逾期正規化為待追蹤；完成、取消及未開始不顯示。
- 進度空白視為 0；卡片只顯示專案識別、雲端資料夾及圖面送審狀態。點進「目前專案」後才讀取完整分析。
- 專案卡依置頂、最後使用時間、使用次數、名稱排序。
- 專案狀態是人工主檔欄位；程式可依進度與目前工作提出建議，但不自動寫回。
- 新回報不再收集「未完成／問題」；舊資料仍保留於歷程，不刪除。
- 專案檔案分類：圖片、CAD、文件、其他；清單依最後修改時間降冪排序，並限制掃描深度與數量避免逾時。
- 週四會議只掃描目前工作，先依來源 ID、再依「專案＋事項＋負責人」去重。
- 報價單價、數量與稅額在伺服器端重算；設備圖片另存 `V21_設備媒體`，不改舊品項主檔。
- 教材可為公司共用或關聯專案；附件優先存入專案 `06_教育訓練` 子資料夾。
