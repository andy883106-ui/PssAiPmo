# V21.1 整合模組與操作流程

## 結論

三個功能應與主程式共用「專案 ID、專案名稱、人員、附件與操作紀錄」，但不要合併成一張巨大資料表。這樣畫面可連動，資料責任仍清楚，未來新增欄位也不會互相影響。

## 操作流程

### 主程式

搜尋或依常用排序選專案 → 查看目前工作 → 新增／編輯／完成工作 → 新增回報 → 後續事項自動成為待追蹤工作。專案頁底部可切換目前專案、圖檔、CAD、文件。

### 新增專案

填專案名稱、客戶、負責人與初始狀態 → 系統產生唯一 `SITE_時間_UUID` 場地代號 → 在專案根目錄建立資料夾及 8 個標準子資料夾 → 寫入 `V21_專案主檔`。

### 教育訓練

搜尋或選教材 → 查看主教材、附件、題庫與完成筆數 → 可編輯教材或上傳附件。關聯專案時，附件放入該專案 `06_教育訓練`；未關聯時放在 V21 共用訓練資料夾。

### 週四會議

開啟頁面查看上次快照 → 按「重新偵測資料庫」 → 重新掃描 V21 目前工作 → 排除完成／取消／未開始 → 去重 → 分成上週追蹤、本週未完成、未來 7 日、會議新增 → 保存本次快照與人員週報摘要。

### 報價設備

以設備名稱、型號或品號搜尋 → 查看既有設備參考與歷史價格 → 補充或更換設備圖片 → 加入報價清單 → 選擇專案、數量、單價與稅率 → 伺服器重算金額並保存草稿。

## 狀態策略

專案狀態不應完全自動修改。資料不完整時，自動狀態容易把「待驗收」錯改為「完成」。V21.1 顯示建議狀態，只有使用者按下儲存才更新主檔；工作完成狀態仍可由任務操作直接更新。

## 附件顯示

所有附件顯示名稱、類型、資料夾路徑與最後修改時間，點選才開啟原檔。圖片用縮圖預覽；CAD 不嘗試在瀏覽器解析，只列檔名與開啟連結；大型資料夾設掃描上限並提示縮小關鍵字。
