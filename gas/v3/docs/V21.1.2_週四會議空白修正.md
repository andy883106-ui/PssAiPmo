# V21.1.2 週四會議空白修正

## 原因

V21.1.1 點選「週四會議」後會先切到空的內容區，再等待後端讀取快照。若最近快照的週起日空白、欄位不完整、格式異常，或資料讀取逾時，後端會回傳失敗；前端只顯示約 3.5 秒的右下角提示，因此看起來像按鈕沒有反應。

## 修正內容

- 切換頁籤後立即顯示四個分類與載入狀態。
- 失敗時保留頁內錯誤訊息，不再只依賴短暫通知。
- 新增「重試載入」與「執行會議診斷」。
- 快照缺欄或日期異常時略過，改用目前 `V21_工作事項` 與 `V21_回報紀錄` 即時計算。
- 快照只檢查最近 2,000 列，並以有效掃描時間選擇最近一份。
- 專案名稱空白時仍可排序，不再中斷整次會議建立。
- 掃描 ID 加入短 UUID，避免同秒重複掃描互相混合。

## 更新與驗證

1. 將 V21.1.2 的全部 `src` 檔案更新到原 Apps Script 專案並儲存。
2. 執行 `runV21SelfTests()`，確認 14 項全部通過。
3. 執行 `setupPssAiPmoV21()`，確認或補建 `V21_週四會議快照`。
4. 在編輯器執行 `diagnoseThursdayMeetingV21()`，查看執行紀錄中的回傳物件；各檢查應為 `ok: true`。
5. 重新部署既有 Web App 為「新版本」。只有儲存程式、不建立新部署版本，`/exec` 仍會執行舊程式。
6. 開啟正式 `/exec`，點「週四會議」，再按「重新偵測資料庫」。

若仍失敗，頁面會顯示固定錯誤框。按「執行會議診斷」後，將每個檢查項目的文字提供給程式管理者即可定位到快照、工作或回報資料。
